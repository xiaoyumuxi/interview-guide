# Security 工程笔记

## JWT 校验

JWT 校验的第一项机制围绕 `signature` 展开。系统先识别请求的边界与状态，再用 signature 保存能够复核的中间信息；这一过程强调确定性、可观测性和失败后恢复，避免把隐含状态散落到调用链中。编号 D1-A 用于区分本段事实。

JWT 校验的第二项机制使用 `audience` 处理异常路径。实现会记录输入、决策和最终结果，并在重复请求到达时依据 audience 保持一致行为；容量达到阈值后应显式降级，而不是静默丢弃数据。编号 D1-B 用于区分这一证据。
